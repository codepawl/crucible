- tool:scene_inspect: two optional fields, profile and profileFrames, give agents the frame time, draw calls, triangles and texture bytes of a scene, which no other tool reports; the detail sits in scene_capabilities profile.
- tool-total: the same two fields on scene_inspect.
- scene:agent-scene: the profile text in scene_capabilities that agents read instead of a longer tool schema.
- scene:agent-scene+lazy: the same text.
- goal:agent-scene: the profile text in scene_capabilities is the shortest form that names every returned field and the 1 to 120 frame bound; the profile code itself loads in the preview page, not in the scene bundle.
