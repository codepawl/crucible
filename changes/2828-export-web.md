- scene_export_web now copies the catalog images that material graph `image` nodes and map sequences read, and the exported page decodes them before it builds the scene (it used to stop with "image ... was not loaded"). A renderer whose memory budget was never set now grows it, up to 512 MiB (1024 MiB on devices with 8 GiB or more), when a scene change adds geometry or textures, so an exported game no longer freezes with "Memory budget cannot hold" at the default 264 MiB, and an exported page shows any error that stops it on screen (Closes #2828, Closes #2832)
