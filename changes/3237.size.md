- scene:agent-scene: the core grows by the field plumbing, the two capability topics and the checks of text panels and billboards; the rasterizer (about 5 KB gzip) and the billboard code load on demand and cost nothing for a recipe that does not use them.
- scene:agent-scene+lazy: the rasterizer, the layout and the billboard sampler are the feature itself; they reuse the bundled DejaVu Sans outlines instead of adding a font or a canvas path.
- goal:agent-scene: a scene that names text or a billboard is the only way to put a sign or a name tag on a Roblox-style film, and the code for it is in the lazy chunks.
- tool:scene_apply: node and material schemas each gain one short field (billboard, text) with the detail in scene_capabilities.
- tool:scene_create: node and material schemas each gain one short field (billboard, text) with the detail in scene_capabilities.
- tool-total: the same two fields in the shared node and material schemas.
- entry:kinetic-text: the entry bundles the agent-scene core, which gains the text and billboard field plumbing (about 800 bytes gzip); the rasterizer and billboard code stay in lazy chunks.
