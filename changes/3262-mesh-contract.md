- `translate` and `transform_selection` can move any set of vertices (`verts`) or edges (`edges`), and every edge rule takes `{ "edges": [[a, b], ...] }` vertex pairs, so a person or an agent can edit one vertex or edge in the recipe. Vertex indices in `verts` and in pairs number the mesh just before that edit (after earlier edits, before the stack), so a `subdivide` or `delete` before it can change what an index points to; an index past the end throws with the vertex count, a repeated vertex or pair counts once, and a pair rule with another key beside it throws (#3262)
