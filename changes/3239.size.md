- scene:agent-scene: about 530 bytes gzip of field names, the position default and the hooks that load the light-parenting chunk and place a light at its parent each frame; the placing code itself is in the lazy chunk.
- goal:agent-scene: the same 530 bytes; lights on parts are the feature the Roblox-style scenes of #3239 need, and a scene without a parent loads none of the new code.
- scene:agent-scene+lazy: the light-parenting chunk adds its code and field checks for recipes with a light `parent` or `face`.
- tool:scene_create: the light fields `parent`, `face` and `faceOffset` attach a light to a part and let a part face shine.
