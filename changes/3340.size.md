- scene:gltf-box+lazy: closed glass instances carry an identifier in the back-face target so a ray takes its exit only from the shape it entered (+134 bytes gzip, lazy liquid shader code only; scenes with no glass or liquid never load it). Without it, nested or overlapping glass bends rays at another shape's back face.
- scene:agent-scene+lazy: same liquid shader code, +137 bytes gzip, lazy for the same reason.
